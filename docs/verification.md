## 本机验收步骤

1. 按 README 将 `dist/` 加载到 Chrome；使用专门的测试配置或测试标签，不拿真实工作标签做批量关闭测试。
2. 打开同网站不同地址、相同地址各数个，另开一个普通窗口，检查分组、窗口标识和重复提醒。
3. 分别验证单页关闭、整组取消、整组确认和重复清理；确认未选中的站点不受影响。
4. 在确认框打开期间增加标签或导航目标页，检查新标签不被加入关闭范围、变化目标被跳过。
5. 点击标题检查跨窗口激活；新增、导航和关闭标签后观察仪表盘更新。
6. 新建标签页验证仪表盘入口和 Google 搜索，另一个 Chrome 配置不应出现在当前列表。
