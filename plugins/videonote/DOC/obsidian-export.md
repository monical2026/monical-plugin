# Obsidian 与本机文件导出（0.5.1）

## 已实现交互

现有“导出”窗口增加两个目的地：下载文件、Obsidian。逐字稿、视频脉络、笔记可以独立勾选，合并为同一份文档；无内容项禁用。初次默认选择已有脉络和笔记，两者都没有时选择逐字稿。逐字稿沿用当前语言模式，笔记沿用既有导出规则（含理解、疑问、AI 回答）。

Obsidian：点击“选择文件夹”，在 macOS 原生窗口中选择知识库根目录或其中的文件夹。首次配置后记住，后续可更换。需要知识库存在 `.obsidian` 目录。导出为 Markdown，不启动外部模型、不上传个人内容。

同一目标目录中检测带同一视频 ID 的 Markdown 文件；如存在先提醒内容可能重合，可取消或继续导出副本。不对手动编辑后的正文作“完全相同”的断言。文件名为 `视频标题 [videoId].md`，后续为 `视频标题 [videoId]（副本）.md`、`视频标题 [videoId]（副本 2）.md`。视频 ID 用于标题变化后识别同一视频；手动删除文件名中的 ID 后不保证识别重复。不同目标文件夹单独判断。不会覆盖任何已有文件。

下载文件：Markdown、TXT、Word 使用 Chrome 下载模式，默认文件名为视频标题及对应后缀，保存为单个文件；PDF 沿用打印窗口，由用户选择“另存为 PDF”。取消不显示保存成功。提交下载后显示“已提交下载”，不把请求提交当成磁盘保存完成。

## 实现与边界

- `extension/src/ui/ExportDialog.tsx`：目的地、内容选择、文件夹设置、重复提醒和操作状态。维持一个导出窗口；现有格式展示与焦点处理仍集中于该组件，后续扩充时可拆分。
- `extension/src/export/obsidian.ts`：校验本机响应、文档编码及 Native 消息大小限制。
- `extension/src/background/index.ts` / `shared/src/index.ts`：新增经过插件 UI 来源检查的下载请求及 Native 操作。0.5.4 起移除 downloads 权限，使用已安装本机组件的 saveExport 操作；不新增访问网站权限。
- `service/src/obsidian.ts`：系统文件夹选择、目标验证、配置持久化和本地写入。目标保存在本机组件配置目录的 `obsidian-target.json`，不进入导出文件或仓库。
- 使用排他创建，并发/同名冲突不能覆盖旧文件。路径只来自系统选择并经过 realpath 检查；标题不能带路径分隔符。文件写入失败移除本次未完成文件，原有文件保持不变。
- 标题截断到 65 个 UTF-16 单元以控制中文文件名长度。超出 Native 消息容量时给出减少内容或下载文件的提示。

需要更新插件和本机组件；已有本机组件已在本次开发中更新，用户仍需在 Chrome 扩展页重新加载插件。首次导出需要用户亲自选择目标文件夹；不自动猜测个人知识库位置。

## 0.5.2 修订

重复提醒改成独立模态确认弹窗（取消 / 继续导出副本），遮罩阻止操作底层导出设置。Markdown 下载使用 text/markdown MIME 与 .md 后缀，TXT 继续使用 text/plain。其余目录选择与不覆盖策略不变。

## 0.5.3 修订

成功状态仅显示“导出成功”，替代前文的路径结果。Markdown 下载增加 onDeterminingFilename 后缀校正，只处理本扩展的 Markdown 下载。


## 0.5.4 修订（替代前述 Chrome 下载路径）

本地文件使用系统存储窗口，不经过 Chrome 下载命名。视频标题及格式后缀直接作为默认名，用户可改名、选目录；PDF 除外。原 onDeterminingFilename 补丁已移除。组件入口 service/src/save-export.ts。


## 当前生效：0.5.5

按用户最新决定撤回 0.5.4 本机存储窗口，恢复 Chrome downloads 模式及权限。下载文件不调用 Native 组件；Native 仅处理 Obsidian 导出等原有功能。默认文件名直接保留视频标题及格式后缀，不使用暂定“下载”名称。此前 saveExport 实现已撤除。
