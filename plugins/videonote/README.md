# VideoNote

源码现位于[插件合集](https://github.com/monical2026/monical-plugin/tree/main/plugins/videonote)，完整 Git 提交历史已保留。原仓库与 0.9.2 Release 保留供历史查阅；日常开发继续在原独立 VideoNote 项目内进行；此目录为合集交付副本。

帮助看视频学习的人阅读双语逐字稿、快速记录重点，并把理解与疑问留成可回看的笔记。

[快速开始](#快速开始) · [功能介绍](#你可以用它做什么) · [常见问题](#常见问题) · [更新日志](DOC/changelog.md)

当前交付版本 **0.9.4**（Windows 实机与真实模型复测仍待完成），支持 YouTube 普通点播视频和 B 站普通 BV 视频的已有字幕。Mac 方案保留，Windows + Chrome 可使用同一浏览器模式安装包；完整平台兼容性仍待验证，范围及限制见[支持范围](#支持范围)。

## 为什么做这个插件

VideoNote 起初来自一个很具体的困扰：英语不够好，但想看 YouTube 上的英文 AI 访谈和分享。

字幕翻译能帮助理解，却没有解决记录的问题。遇到值得留下的内容，仍然要暂停视频、切换软件、手动打字。一个两小时的视频，连看带记可能花上三个小时。好不容易看完，过一阵子又想不起重点，也找不到当时的想法。

因此，VideoNote 希望让这件事更顺手：观看前先浏览逐字稿，知道视频大致在讲什么；观看时快速标记有价值的内容；看完再整理视频脉络，写下自己的理解和疑问，方便以后查找。

这个项目也分享给有相同困扰的人，希望大家可以直接使用，不必重复做一套工具。

## 你可以用它做什么

### 阅读双语逐字稿

在视频旁阅读带时间的逐字稿，外语内容可切换原文、中文和双语。点击段落回到对应视频位置，也可以自由浏览文字，再通过“跟随”回到当前播放位置。中文原稿直接阅读，不重复展示两份中文。

### 梳理视频脉络

主动使用 AI 整理全篇总结、议题、知识点、金句和方法，结合时间引用回看原视频。整理依据逐字稿，不识别画面；视频里只展示而没有讲出的操作步骤，不能靠它补全。

### 记录理解与疑问

观看时用快捷键记录当前片段，也可以选中文字摘录。笔记里保留来源时间，并分别填写“我的理解与价值”和“我的疑问”。需要进一步讨论时，主动向 AI 提问，回答单独保存，方便以后回看。

### 回看历史记录

在历史页集中阅读已保存的逐字稿、视频脉络和笔记，继续编辑或提问。可以搜索视频标题、笔记摘录、个人理解和疑问；AI 回答不参与搜索。

### 导出学习成果

按需选择逐字稿、脉络和笔记，导出 Markdown、TXT、Word，或通过打印窗口另存为 PDF。浏览器模式首次连接并授权 Obsidian 文件夹后会记住知识库，后续权限有效时直接导入 Markdown，无需本机组件（0.9.4 待验收）；本机模式保留原导出路径。

## 快速开始

### 使用前准备

准备 Chrome 和一个支持的视频。第一次建议选择有字幕的视频，先体验阅读和记录，再按需配置 AI。

下载 [VideoNote-0.9.4-chrome.zip](https://github.com/monical2026/monical-plugin/raw/refs/heads/main/downloads/videonote/VideoNote-0.9.4-chrome.zip)，不需要安装 Node.js、pnpm 或本机组件。安装包由本合集直接提供；历史 0.9.2 Release 保留供查阅。GitHub 的“Code → Download ZIP”仍是源码，不能直接加载；源码构建说明放在[开发说明](DOC/development.md)。

### 安装

1. 下载成品 ZIP 后先解压，并把文件夹放在准备长期保留的位置。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分界面称“加载未打包的扩展程序”），选择包含 `manifest.json` 的成品文件夹。成品包解压后选择 `VideoNote` 文件夹（开发者构建对应 `extension/dist`）。
4. 0.9.4 首次安装会自动打开设置页，可先配置服务；更新不重复打开。之后打开或刷新一个支持的视频页面，点击“VideoNote”入口。

详细说明见[安装与使用指南](DOC/user-guide.md)。

### 按需配置

直接读取可获取的已有字幕、使用可用的 Chrome 本地翻译和记录笔记，不需要 LLM API Key。字幕能否取得取决于视频及平台；本地翻译取决于浏览器能力与语言支持。

新安装默认使用浏览器模式。AI 整理、AI 提问、大模型翻译和 Supadata 可直接在扩展中使用：在设置页创建密钥库密码，添加服务与 API Key，按提示授权服务域名，测试模型并保存，再选择任务使用的模型。浏览器重启后输入密钥库密码解锁即可，不必重新填写 API Key。

原有本机模式保留，旧版升级继续使用原模式。系统钥匙串与 Codex CLI 仍需可选本机组件，详见[开发说明](DOC/development.md#安装本机组件)。两种模式的服务配置独立，不自动迁移密钥。

### 完成第一条笔记

打开有字幕的视频 → 浏览逐字稿 → 选中一段值得记录的文字 → 点击笔记操作 → 写下自己的理解或疑问 → 点击“完成”。以后点击笔记时间即可回到视频位置。

观看中也可以使用“快速记笔记”快捷键。实际按键在“设置 → 快捷键”里查看和修改。

## 一个完整的使用示例

假设你准备看一段英文 AI 访谈：

1. **先阅读**：打开逐字稿，切到双语模式，先看看谈到了哪些内容。
2. **边看边摘录**：遇到有启发的观点，用快捷键记录，或选中文字保存。
3. **写下理解**：在笔记里补一句“这个观点对我有什么帮助”，记下仍不理解的地方。
4. **需要时提问**：配置好 AI 后，发送具体问题；回到视频核对回答和原意。
5. **整理与回看**：生成视频脉络，结合自己的笔记检查漏掉的重点。以后通过历史记录查找，或导出到自己的资料库。

## 支持范围

| 项目 | 当前范围 |
| --- | --- |
| YouTube | 普通 watch 点播页；优先读取已有字幕，必要时可配置 Supadata；无字幕生成须逐次确认 |
| B 站 | 普通 BV 视频及多 P 的已有字幕；部分字幕需要登录；无字幕转写尚未接入 |
| 浏览器与系统 | Mac 方案保留；Windows + Chrome 使用同一成品包，完整兼容性仍待验证；Linux 和其他浏览器未完成支持 |
| 本地翻译 | 使用 Chrome Translator API，受浏览器、设备与语言支持影响；首次使用可能需要下载模型 |
| 暂不支持 | YouTube Shorts、直播、站外嵌入视频、小红书、抖音，以及画面识别/OCR |
| 数据使用 | 当前电脑、本地浏览器配置文件保存；没有跨设备自动同步 |

## 数据、隐私与费用

- **学习记录**：逐字稿、译文、脉络、笔记和 AI 回答保存在当前浏览器的本地数据库。卸载扩展或清理浏览器数据可能导致记录丢失，重要内容请先导出。
- **外部服务**：读取字幕需要访问对应视频平台；使用 Supadata 时向该服务提交视频标识及所需任务信息。主动调用 AI 翻译或整理时，相关逐字稿会交给配置的模型服务。
- **AI 提问**：发送当前问题、相关摘录及最近的问答上下文；个人理解字段不会自动附带发送。不要把不愿交给所选服务的内容写入发送的问题或摘录。
- **密钥**：浏览器模式用自设密码派生密钥，加密保存 API Key；解锁状态仅保留在浏览器会话中。忘记密码需重置密钥库并重新填写 Key，笔记不受影响。本机模式继续使用 macOS 系统钥匙串或 Windows 凭据管理器。细节见[浏览器模式](DOC/browser-mode.md)。
- **费用**：Chrome 本地翻译不调用云端 LLM。外部模型和字幕服务可能消耗额度或产生费用，以所选服务为准。无字幕生成前会展示预计消耗并要求确认；本地翻译失败不会自动切换到付费大模型。

## 常见问题

**下载整个项目后，为什么加载失败？**

请使用成品 ZIP，解压后选择其中的 `VideoNote` 文件夹。GitHub 的源码 ZIP 不能直接加载。构建方法仅面向开发者，见[开发说明](DOC/development.md)。

**一定要配置 AI 才能使用吗？**

不用。可以先读取可获取的已有字幕、记录笔记和导出文件。AI 整理、提问及大模型翻译才需要相应模型连接；Supadata 字幕服务需要单独配置。

**为什么有的视频没有逐字稿？**

视频可能没有可读取的字幕，也可能受到登录、网络或平台限制。B 站画面里带字幕，不一定意味着存在可读取的字幕轨道。目前 B 站不支持无字幕转写。

**中文翻译失败了怎么办？**

保留原文继续阅读和记录，查看页面的错误提示。本地翻译依赖 Chrome 的语言能力；需要使用大模型翻译时，请先配置服务，再主动点击翻译。

**关掉视频以后，笔记在哪里？**

在插件的“历史记录”里。也可以在非视频页面点击浏览器工具栏的 VideoNote 图标进入历史页。记录在当前浏览器本地，换电脑不会自动出现。

**快捷键没有反应怎么办？**

到“设置 → 快捷键”检查实际绑定。若未设置或与其他快捷键冲突，点击修改入口，在 Chrome 的快捷键页面重新指定。
