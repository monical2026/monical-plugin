# 实施前技术验证

这些是独立验证夹具，不是产品扩展，不包含真实 API key。浏览器原生 JavaScript 用于直接加载，不引入构建依赖；产品源码仍按 TypeScript 方案实施。

## Chrome 本地翻译

在实际 Chrome 的扩展管理页启用开发者模式，加载本目录的 `translator/` 文件夹；打开该扩展的选项页，点击“检测并翻译样本”。记录浏览器版本、来源、语言对状态、模型下载、译文与耗时。首次可能下载模型，失败不调用任何云端服务。

本夹具只验证独立扩展文档，不证明后台 Worker、页面面板或关闭面板的快捷摘录已经可用。现有 8 组人工编写样本：否定与操作顺序、数字百分比、访谈口语、否定范围、技术术语、条件步骤、指代、习语与因果。没有真实私人逐字稿。逐项记录意义错误与表达问题；不把自编样本通过当作真实长视频验收。

## 钥匙串只读预检

从项目根目录运行：

```sh
swiftc scripts/probes/keychain/check.swift -o artifacts/probes/keychain-check
artifacts/probes/keychain-check
```

仅随机查询一个不存在的条目，期望系统返回条目不存在。不读取现有秘密、不创建或删除凭据。此检查不等于密钥写入、授权体验、跨进程读取或 Native Messaging 已经通过。

## client=gtx 对照探针

`compare-gtx.mjs` 读取先前本地样本结果，向指定 gtx 端点逐条提交相同的人工样本，结果写入 artifacts/probes/gtx-comparison.json。不读取私人文本或 API key。遇到 HTTP 429/403 即停止，不自动重试。运行前确保产物目录和原样本存在；网络按本机实际配置使用，不写死代理端口。当前最近一轮受到 429 限制，尚无云端译文对照结果。
