# Tab Haven · 标签小憩

当前版本：0.9.0。版本递增规则见 [AGENTS.md](AGENTS.md#版本递增规则)。

一个把 Google 搜索与标签整理放在一起的 Chrome 新标签页插件。默认收起网站卡片，展开后可切换或关闭单页，整组关闭需要确认，重复页面只在仪表盘内提醒。

## 开发与加载

使用 Node.js 22.12+（当前开发环境为 26.3.1）、pnpm 11.25.0。

```sh
pnpm install
pnpm dev
```

本地网页预览使用明确标识的示例数据，不会读取或关闭真实标签。要使用真实功能：

```sh
pnpm run lint
pnpm test
pnpm run build
```

1. 在 Chrome 中打开 `chrome://extensions`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
3. 新建标签页，按 Chrome 提示保留新的新标签页设置。
4. 更新代码后重新构建，在扩展管理页面点击刷新，再刷新仪表盘。

不同 Chrome 配置需要各自安装。禁用或移除插件后，Chrome 会按其他扩展和浏览器设置恢复新标签页。

## 常用网站快捷入口

左侧用于进入网站首页，中间继续管理当前标签。默认提供 B 站、抖音、知乎、YouTube；入口独立于已打开标签，不保存视频或文章分组。

- 点击入口：查找当前配置普通窗口里地址完全相同的首页，存在就激活，否则新开首页；不会替换已有视频或文章。不同子域、协议及带参数的首页不视为同一地址。
- “添加网站”：填写名称和网址，仅保存网址的域名首页，自动去除路径、查询参数和片段。
- “管理”：使用上下箭头排序，或移除入口。移除不会关闭已打开页面。
- 配置使用当前扩展来源的 localStorage 本地保存，刷新、重启后保留，不跨 Chrome 配置同步。普通网页演示与实际扩展的配置相互独立。
- 左栏仅显示 Logo，每行四个，超出后换行；名称通过悬停提示和无障碍标签提供，无图标时显示首字占位。顶部侧栏轮廓图标可收起/展开侧栏，日常操作不显示常驻成功提示。
- “管理”弹窗提供“分组 / 不分组”：默认按网站分组；不分组逐行显示全部页面，支持搜索和单页关闭，不显示整组关闭按钮。两种模式都保留重复清理。
- 侧栏收缩与分组选择保存在本机，刷新后保留；窄屏将快捷入口放到主内容上方。

## 使用与规则

- 展开的网站分组占满一行，每页显示小图标、完整换行标题、地址与窗口状态；标题不截断，悬停可读完整标题和地址。
- 中央输入框搜索 Google；管理区输入框仅查找已打开标签的标题、网址和网站名称。
- 按可注册域名分组，例如知乎主站与专栏归为一组；私有托管域名分别处理，例如不同的 `github.io` 站点不混合。
- 卡片首次按网站名称排序，同一次页面打开期间保持已有顺序，新出现的网站追加到末尾；主动展开某组时，该组移至管理区最前并立即滚动到组标题，其余组保持相对顺序。收起后保留当前位置，自动刷新和搜索不触发滚动；刷新页面后重新按名称排序。颜色固定绑定域名，不随位置或数量变化。
- 搜索时显示“匹配 X 页 / 共 Y 页”；整组叉号关闭始终包含该网站未匹配的标签，确认框明确说明范围。
- 当前配置下所有普通窗口统一展示；隐身窗口和本插件仪表盘不参与管理。
- 重复识别仅针对 HTTP/HTTPS 页面，比较浏览器规范化后的完整地址。查询参数、参数顺序和 hash 保留，不因标题一致而合并。
- 清理重复项优先保留固定标签，再优先活动标签、最近访问标签，最后按标签 ID 稳定选择。确认框列出待关闭项。
- 固定标签仍可被明确关闭或整组关闭。整组关闭以确认时的目标为准；执行前跳过已导航、消失的目标。关闭最后一个标签可能关闭其所在窗口。
- 普通页面关闭可能导致未保存的内容丢失；插件不承诺恢复表单状态。重复清理时若保留项已消失，会跳过相应待删项。
- Chrome 内部页面、本地文件等单独归类，不做重复识别。

## 工程与验证

- `src/sidebar.js`、`src/shortcuts.js`：首页入口界面、本地保存与首页复用规则。
- `src/main.js`：界面、确认弹窗和事件刷新。
- `src/model.js`：分组、重复检测和关闭快照校验。
- `src/api.js`：Chrome API 与独立演示数据适配。
- `src/presentation.js`：稳定排序、域名配色和 favicon 地址构造。
- `src/style.css`：响应式界面样式。
- `public/manifest.json`：Manifest V3 插件清单；Vite 构建时复制到 `dist`。
- `tests/model.test.js`：使用 Node.js 内置测试工具验证关键逻辑。
- [AGENTS.md](AGENTS.md)：项目协作约定与产品范围。
- [验证记录](docs/verification.md)：实际检查结果与验收限制。

CI/可复现安装使用 `pnpm install --frozen-lockfile`。项目使用原生 JavaScript，不提供 TypeScript 类型检查脚本。`pnpm test` 单次执行，失败返回非零状态。构建成功并不代替真实浏览器验收。

## 隐私与权限

申请 `tabs` 权限读取标题、网址和标签状态，使用 `favicon` 权限通过 Chrome 内置接口读取网站图标。没有后台服务器、内容脚本、跟踪代码或云端同步；标签数据只在当前页面内存中处理。搜索时只将用户主动提交的查询发送给 Google，不发送标签清单。网站图标通过 Chrome 的扩展 favicon 接口获取，不接入第三方图标代理；加载失败、特殊页面和普通网页演示模式使用文字占位。

下载 `tab-haven-0.9.0.zip` 后先解压，打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `tab-haven-0.9.0` 文件夹。安装包已经构建完成，无需安装 Node.js 或 pnpm。不要直接选择 ZIP 文件，也无需下载整个合集。

## 重新打开与固定标签

- 标签行的叉号左侧提供图钉按钮：点击固定到 Chrome 原生标签栏，再次点击取消固定。固定后图钉高亮，行内显示“已固定”。固定不等于收藏，也不阻止用户关闭该标签。
- 单页关闭、整组关闭、重复清理成功后，右上角的回转箭头恢复按钮变为可用，悬停显示待恢复数量。点击展开最近关闭列表，显示标题和网址，选择一项只恢复该页面；只恢复实际关闭成功的标签。
- 关闭与恢复成功不弹出底部提示，仅在操作失败或目标发生变化时提示。
- 恢复使用原始完整网址，尝试放回原窗口、原位置并保留固定状态，后台打开；原窗口不存在时在当前窗口打开。失败项保留，可再次点击重试，成功项不会重复打开。
- 恢复记录自关闭起保留 30 分钟，最多保留最近 100 页；过期或超限自动移除记录，不影响已打开页面。列表显示剩余分钟数，恢复失败重试不延长有效期。
- 恢复记录仅在当前仪表盘页面存活期间保留；刷新、关闭该仪表盘会清空，不跨仪表盘共享。不保证恢复网页的临时输入、滚动位置、登录后的页面状态或视频播放进度。浏览器限制打开的特殊页面可能恢复失败。
- GitHub 合集安装包同步为 0.9.0；也可加载本地 `dist/`。

固定与重新创建标签使用 [Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)，不新增权限。

## 0.4.0：整组关闭与多选关闭

网站卡片右上角叉号关闭整组，始终弹窗确认。点击“多选”展开页面并显示勾选框，可跨网站选择后点击“关闭所选”，确认弹窗列出标题、网址和固定状态。取消无影响；修改或清空搜索会取消勾选，退出多选或清空选择也会取消勾选。页面已关闭或地址已变化时移除选择。确认仅处理弹窗打开时的快照，不包含后续新增页面；成功关闭后支持原有限时恢复。

## 0.5.0：出声标签与静音

出声或已静音的标签显示扬声器按钮，点击切换 Chrome 标签静音状态；普通无声页面不显示声音按钮。网站分组收起时也显示出声/静音页数。状态通过 Chrome 标签更新事件刷新，已静音页面不会计入正在出声。静音同时尝试暂停网页中的音视频；出声检测可能有浏览器自身的短暂延迟。0.5.1 增加 scripting 权限与按网站申请的可选访问权限。GitHub 下载包与本地构建均为 0.9.0。

### 静音与暂停联动（0.5.1）

首次操作网站时 Chrome 会请求该网站的访问权限，用于暂停网页播放器。按钮同时静音并暂停正在播放的 HTML 音视频；再次点击恢复声音，并尝试继续插件暂停的同一媒体，不启动原本已暂停的内容。支持普通页面、开放 Shadow DOM 与同源嵌入播放器。跨域嵌入、特殊播放器或网站自动播放逻辑可能无法控制；权限拒绝或执行失败时只执行原生静音并明确提示，不宣称暂停成功。继续播放可能受网站或浏览器播放策略限制。刷新目标网页会清除暂停记录。

实现依据：[Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

### 原页面播放自动恢复声音（0.5.2）

由插件静音并暂停后，用户在原页面点击播放，会自动解除本插件设置的标签静音，无需回到仪表盘。仅处理插件暂停的同一媒体及用户主动播放；不会解除浏览器菜单或其他扩展设置的静音。网站自动播放、换源或刷新页面不触发这一恢复。新增后台脚本接收播放器事件，仪表盘关闭后仍可响应；不新增权限。

## 0.5.3 标签列表更新入口

移除搜索框旁常驻的刷新按钮。标签变化及返回仪表盘时仍会自动更新；仅在读取失败时显示错误提示和“重试”，读取成功后自动隐藏。更新失败时保留上次成功读取的列表。

## 0.6.0：单页网站直接切换

按网站分组且未进入多选模式时，只有一个标签的网站点击 Logo 或名称直接切换到原标签及其窗口，箭头显示为 ↗。旁边“⋯”可展开页面操作，继续使用固定、声音和关闭功能。多页网站仍展开列表；搜索仅匹配一页不视为网站只有一页。多选模式保持展开勾选；不分组模式仍点击页面行切换。GitHub 包与本地版本均为 0.9.0。

## 0.7.0：整组关闭保护固定标签

整组关闭默认保留已固定页面。弹窗分别标明关闭数量与保留页面，可勾选“同时关闭已固定页面”纳入范围；取消勾选恢复保护。全部固定时默认确认按钮禁用。每次弹窗重新默认保护，确认期间新固定的标签也会跳过；不增加快照以外的页面。单页关闭、多选明确选中的页面及重复清理沿用原有行为。本地与 GitHub 安装包均为 0.9.0。

## 0.8.1：全选当前结果

多选工具栏增加“全选当前结果（N 页）”，只勾选当前搜索匹配的页面，分组与不分组模式行为一致。修改或清空搜索后立即取消之前的勾选，搜索本身不自动选择；可逐项取消，也可清空全部选择。无匹配或当前结果已全部选中时按钮禁用。没有搜索词时全选全部待管理页面；包含固定页面，关闭所选仍按明确选择范围弹窗确认。GitHub 安装包同步为 0.9.0。

全选统一覆盖当前关键词命中的所有网站，不限制单一来源。可逐项勾选或全选后逐项取消；搜索只匹配已打开标签的标题、网址和网站名称，不搜索网页正文。页面更新后不再匹配的已选项也会移除。

## 0.9.0：状态快捷筛选

全部、正在出声、已固定三个入口单选切换，与关键词交集过滤，数量反映当前关键词匹配情况。出声不包括已静音页面；固定与声音变化后自动更新列表。切换筛选清空旧勾选，全选只选择当前显示结果。整组叉号仍针对该网站全组，确认框明确告知包含未匹配项并保留固定保护；只关结果请用多选。刷新默认回到全部。GitHub 安装包同步为 0.9.0。
