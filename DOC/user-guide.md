# VideoNote 安装与使用指南

产品介绍和支持范围见[README](../README.md)。Mac 方案保留；Windows + Chrome 可使用同一浏览器模式安装包，完整兼容性仍待验证，详见 [Windows 支持](windows-support.md)。

## 安装扩展

从 [GitHub Release](https://github.com/monical2026/YouTube---/releases/tag/v0.9.2) 下载 [VideoNote-0.9.2-chrome.zip](https://github.com/monical2026/YouTube---/releases/download/v0.9.2/VideoNote-0.9.2-chrome.zip) 成品包，无需安装开发工具或本机组件。GitHub 的 Code → Download ZIP 仍是源码。

下载后按以下步骤安装：

1. ZIP 文件先解压，文件夹放到长期保留的位置，不要加载后删除或随意移动。
2. 在 Chrome 地址栏输入 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分界面称“加载未打包的扩展程序”）。
4. 选择直接包含 manifest.json 的成品文件夹；成品解压后为 VideoNote 文件夹，不是 ZIP 本身或项目根目录。
5. 打开或刷新普通 YouTube 点播页或 B 站普通 BV 视频页，点击 VideoNote 入口。

只需本地加载，不需要点击 Chrome 的“打包扩展程序”。更新成品后，在扩展管理页重新加载，再刷新视频页。

## 选择需要的配置

先选择有可读取字幕的视频，体验逐字稿和笔记。本地翻译是否可用取决于 Chrome 能力、设备及语言支持；首次使用可能需要下载模型。

新安装默认选择“浏览器模式”。使用 AI 或 Supadata 时：

1. 打开设置，创建至少 10 个字符的密钥库密码并妥善保存。
2. 添加服务，填写 HTTPS 服务地址、API Key 和模型。
3. 测试连接或保存时，允许 Chrome 访问你选择的服务域名。
4. 在任务分工中选择模型，保存全部设置。
5. 重启浏览器后，在设置页用密码解锁；无需重新填写 Key。

忘记密码无法恢复原密钥库；可重置并重新填写 Key，笔记不会被删除。旧版升级继续使用本机模式，可以主动切换；两种模式配置独立。本机 Codex、系统凭据库和 Obsidian 直接写入仍需可选组件，安装见[开发说明](development.md#安装本机组件)。

使用收费服务前查看服务额度与费用提示。无字幕生成须每次确认；本地翻译失败不会自动使用付费模型。

## 阅读与记笔记

- 打开面板后读取该视频已有字幕；外语内容可切换原文、中文和双语，中文原稿直接展示。
- 点击逐字稿段落可定位视频并播放；选中文字用于摘录。手动浏览后，通过“跟随”定位当前播放段落。
- 使用快捷键记录当前片段，或选择文字后使用笔记操作。填写“我的理解与价值”“我的疑问”，点击“完成”。
- 点击笔记时间可回到对应视频位置；右上角垃圾桶会先询问是否删除，确认后才删除该笔记。
- AI 问答需要主动发送；回答与个人理解分别保存。同一笔记连续发送相同问题会被阻止，避免重复请求。

## 快捷键

在“设置 → 快捷键”查看实际绑定。默认按键如下，已有自定义或浏览器冲突时以页面显示为准：

| 操作 | macOS | 其他系统的预设按键 |
| --- | --- | --- |
| 打开 VideoNote | Command + Shift + U | Ctrl + Shift + U |
| 快速记笔记 | Command + Shift + Y | Ctrl + Shift + Y |

其他系统的按键声明不代表完整支持已经验证。点击“修改快捷键”进入 Chrome 修改，浏览器自动保存；回到设置页查看更新后的绑定。

## 历史与导出

通过插件内“历史记录”入口，或在非视频页面点击工具栏 VideoNote 图标进入历史页。左侧选择视频，右侧阅读逐字稿、脉络或笔记，也可以继续编辑与提问。搜索包括标题与笔记内容，不包括 AI 回答。

导出时选择要保留的内容与文件格式：Markdown、TXT、Word，或经打印窗口另存 PDF。Obsidian 导出需安装本机组件，再从已登记知识库列表选择目标；同一视频重复导出时会提示是否生成副本。

记录保存在当前浏览器本地，没有跨设备自动同步。卸载扩展、清理浏览器数据或换电脑前，先导出重要内容。

## 遇到问题

先查看[常见问题](../README.md#常见问题)。本机组件连接失败时，检查组件是否安装，以及注册时的 Node 路径是否仍有效；技术排查见[开发说明](development.md)。

仍无法解决时，到 [GitHub Issues](https://github.com/monical2026/YouTube---/issues) 提供版本、系统、浏览器、平台、复现步骤和错误提示。不要附带密钥或私人笔记。

## 保存设置与更新安装包

API Key 输入框下可直接进入 DeepSeek、智谱、OpenAI 或 Supadata 官方控制台。自定义服务需到对应服务商网站创建 Key，控制台网址不要填入 Base URL。

点击保存后查看按钮附近结果。浏览器模式首次填写 Key 前先创建密钥库，之后每次新会话需解锁；失败时保留输入，按具体提示处理后再次保存。保存成功后连接显示“已保存”，Key 输入框清空并提示已安全保存。

更新 ZIP：将新版 VideoNote 文件夹内的内容覆盖到之前加载的同一文件夹，保留原路径；进入 chrome://extensions 点击该扩展的重新加载，再刷新视频页。不要卸载旧扩展，以免删除本地记录。

## 连接 Obsidian（0.9.8 待验收）

浏览器模式也使用可选本机连接组件。下载对应系统的完整安装包，加载扩展后从导出窗口复制安装连接编号，双击安装连接程序并粘贴编号，安装后点击“检查 Obsidian 连接”。未连接、未安装 Obsidian 或没有有效知识库时均不可选；安装软件并打开知识库后重新检查。正常后从已登记知识库列表选择目标，导出内容直接写入；重复视频先确认再生成副本。

旧版“选择文件夹并导入”已停用，既有文件保持不变。完整步骤、系统要求与状态解释见 [Obsidian 安装指南](obsidian-install.md)。

浏览器模式的脉络使用设置中“模型分工 → 中文摘要与视频脉络”选中的 API 模型；保存服务及 Key 并解锁密钥库后即可运行，不使用本机 Codex。

首次安装 0.9.4 自动打开设置页；普通更新不会再次自动打开。脉络来源编号不完整时最多追加一次校正模型请求，可能额外消耗模型额度；仍失败则停止并保留已有内容。


## 脉络失败时复制诊断（0.9.5）

更新插件到 0.9.5，刷新视频页，再点击一次“脉络”。如果失败，点击错误提示下方的“复制脉络诊断”，粘贴给开发者即可；如果自动复制受限，点击展开的文本框，按 Ctrl+C（Mac 为 Command+C）手动复制。没有错误时，也能在“视频脉络”页复制该视频上次已保存的诊断。不需要打开后台开发者工具，不要复制密钥或导出整份浏览器网络日志。

诊断只记录阶段、状态码、耗时和字段类型，不包含字幕或笔记正文；它不会额外调用模型，重新整理本身仍可能产生通常的模型费用。
