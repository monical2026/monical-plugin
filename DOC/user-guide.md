# VideoNote 安装与使用指南

产品介绍和支持范围见[README](../README.md)。Mac 方案保留；Windows + Chrome 适配已加入，尚待实机验收，详见 [Windows 支持](windows-support.md)。

## 安装扩展

目前尚未发布公开成品安装包。GitHub 的 Code → Download ZIP 是源码；只有源码时，需先按[开发说明](development.md)构建，或请熟悉构建的人协助准备成品文件夹。

拿到成品后：

1. ZIP 文件先解压，文件夹放到长期保留的位置，不要加载后删除或随意移动。
2. 在 Chrome 地址栏输入 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分界面称“加载未打包的扩展程序”）。
4. 选择直接包含 manifest.json 的成品文件夹；本项目构建后为 extension/dist，不是整个项目根目录，也不是 extension 源码目录。
5. 打开或刷新普通 YouTube 点播页或 B 站普通 BV 视频页，点击 VideoNote 入口。

只需本地加载，不需要点击 Chrome 的“打包扩展程序”。更新成品后，在扩展管理页重新加载，再刷新视频页。

## 选择需要的配置

先选择有可读取字幕的视频，体验逐字稿和笔记。本地翻译是否可用取决于 Chrome 能力、设备及语言支持；首次使用可能需要下载模型。

需要 AI 整理、提问、大模型翻译、Supadata 字幕服务或 Obsidian 导出时，先安装本机组件。目前还没有一键安装器，具体步骤在[开发说明](development.md#安装本机组件)。完成后打开插件设置页，添加所需连接、测试指定模型并保存，在任务分工中选择相应模型。服务设置的详细设计见[服务设置](service-settings.md)。

使用收费服务前查看服务额度与费用提示。无字幕生成须每次确认；本地翻译失败不会自动使用付费模型。

## 阅读与记笔记

- 打开面板后读取该视频已有字幕；外语内容可切换原文、中文和双语，中文原稿直接展示。
- 点击逐字稿段落可定位视频并播放；选中文字用于摘录。手动浏览后，通过“跟随”定位当前播放段落。
- 使用快捷键记录当前片段，或选择文字后使用笔记操作。填写“我的理解与价值”“我的疑问”，点击“完成”。
- 点击笔记时间可回到对应视频位置；右上角垃圾桶会先询问是否删除，确认后才删除该笔记。
- AI 问答需要主动发送；回答与个人理解分别保存。同一笔记连续发送相同问题会被阻止，避免重复请求。

## 快捷键

在“设置 → 快捷键”查看实际绑定。默认按键如下，已有自定义或浏览器冲突时以页面显示为准：

| 操作 | macOS | 其他系统的预设按键 |
| --- | --- | --- |
| 打开 VideoNote | Command + Shift + U | Ctrl + Shift + U |
| 快速记笔记 | Command + Shift + Y | Ctrl + Shift + Y |

其他系统的按键声明不代表完整支持已经验证。点击“修改快捷键”进入 Chrome 修改，浏览器自动保存；回到设置页查看更新后的绑定。

## 历史与导出

通过插件内“历史记录”入口，或在非视频页面点击工具栏 VideoNote 图标进入历史页。左侧选择视频，右侧阅读逐字稿、脉络或笔记，也可以继续编辑与提问。搜索包括标题与笔记内容，不包括 AI 回答。

导出时选择要保留的内容与文件格式：Markdown、TXT、Word，或经打印窗口另存 PDF。Obsidian 导出需安装本机组件，再主动选择本机目标文件夹；同一视频重复导出时会提示是否生成副本。

记录保存在当前浏览器本地，没有跨设备自动同步。卸载扩展、清理浏览器数据或换电脑前，先导出重要内容。

## 遇到问题

先查看[常见问题](../README.md#常见问题)。本机组件连接失败时，检查组件是否安装，以及注册时的 Node 路径是否仍有效；技术排查见[开发说明](development.md)。

仍无法解决时，到 [GitHub Issues](https://github.com/monical2026/YouTube---/issues) 提供版本、系统、浏览器、平台、复现步骤和错误提示。不要附带密钥或私人笔记。
