# 独立设置页与 LLM、外部服务连接方案

> 0.9.1 新增默认浏览器模式，下文本机组件与系统凭据库设计仍适用于可选本机模式。浏览器模式配置、加密、权限及限制以 [browser-mode.md](browser-mode.md) 为准。

0.6.1 增量：B 站已有字幕使用当前浏览器的站内登录，不新增服务表单或 API Key；受限字幕需本人在 Chrome 登录 B 站。现有 LLM 连接复用于 B 站脉络和主动笔记提问。B 站无字幕转写尚未接入，不能选 Supadata 自动回退；后续通用转写方案见 [多平台适配](multi-platform-adaptation.md)。

> 状态：需求和技术设计，尚未实现或连接真实账号。用户已明确要求专门网页配置 LLM 和其他外部服务 API。
> 视觉以 [design.md](design.md) 为准，目录以 [architecture.md](architecture.md) 为准。本文件规定配置字段、调用关系和保存规则。

## 一、设置页入口

- 使用扩展自己拥有的完整网页 `options.html`，在 Chrome 独立标签页打开，无需先打开某个视频。
- YouTube 面板齿轮、未配置服务提示、Chrome 扩展选项均进入同一页面；重复操作尽量复用该页。
- Manifest 使用 `options_page: "options.html"`，由 `chrome.runtime.openOptionsPage()` 打开。Chrome 官方支持完整标签页设置页。[官方选项页说明](https://developer.chrome.com/docs/extensions/develop/ui/options-page)
- 设置页是用户主动打开的管理界面，与“其他网站不注入插件”不冲突；不会往其他网页放浮钮。
- 设置页仅管理配置，不要求用户在源码或配置文件中手写 API key。

## 二、栏目与字段

### 常规

主题、默认逐字稿模式、AI 输出语言（默认中文）、实际快捷键及其 Chrome 修改入口。偏好存在当前电脑，不开启跨设备同步。

### LLM 服务

第一版仅配置文本翻译与整理能力，不要求视觉模型，不新增图片、OCR 或视频分析服务表单。字幕生成仍由字幕服务负责。

支持保存多份服务连接资料，分别命名，选择一份作为默认。第一版落实 OpenAI-compatible Chat Completions 协议适配器，不等于所有自称兼容的供应商都已经可用。原生 Anthropic、Gemini、Responses 等协议作为后续适配器，未实现前不放可选假入口。

| 字段 | 显示与规则 |
| --- | --- |
| 连接名称 | 自定义，例如“日常翻译”；这是连接标签，不是模型名称 |
| 协议类型 | 首版显示实际支持的兼容协议 |
| Base URL | 填 API 根地址，不填聊天网页；展示最终请求主机和端点预览，统一尾斜杠，避免重复拼接 /v1 |
| API key | 掩码输入；保存后仅显示“已配置／未配置／来自环境变量”，不回填真实值 |
| 默认模型 | 可选拉取列表，也可手动输入完整 model ID；列表失败不阻止手动配置 |
| 启用状态 | 暂停连接不删除凭据或旧结果；仍被任务使用时提示影响范围 |
| 超时与并发 | 放入高级设置，初始建议 60 秒请求超时、并发 2，属于待验证默认 |
| 最大输入/输出预算 | 可选高级配置；按供应商能力解释，不把字符数等同于 token 数 |

仅采用各模型支持的参数；temperature、结构化输出等选项须按能力启用，不无条件发送统一参数。不能只因列表中有某个模型就宣布翻译和分析已可用。

DeepSeek 官方说明可用兼容格式调用，可作为以后验证样本之一；本项目不因此固定它为默认供应商，也不硬编码当前模型名。[官方接入说明](https://api-docs.deepseek.com/)

### 字幕与外部 API

第一版明确提供 Supadata 连接卡片：API key、连接状态、字幕策略（仅已有字幕／无字幕时询问生成）、超时及生成额度限制。界面强调获取现成字幕与生成字幕的成本不同。允许生成只表示可展示确认入口，不能关闭每次生成前的预计消耗确认；默认不使用供应商 auto 自动生成。

默认使用内置官方端点；普通使用无需修改地址，避免把 LLM 的 Base URL 错当字幕端点。没有官方余额接口证据时，只显示本机已观测用量及官方控制台入口，不把估算称为真实剩余额度。

其他服务通过独立适配器与对应表单增加，不提供“随便填任意 API 就自动能用”的承诺。首版先支持 Supadata 与上述 LLM 协议，其他供应商属于扩展点。

### 任务与模型分配

| 任务 | 默认使用什么 | 可配置行为 |
| --- | --- | --- |
| 获取/生成逐字稿 | Supadata | 字幕模式、是否允许生成和额度上限 |
| 中文翻译及双语摘录补齐 | 优先 Chrome 本地翻译，待实测 | 展示支持状态、首次下载及重试；不可用不自动云端回退 |
| 主动大模型翻译 | 用户配置的 LLM 连接与模型 | 当前段按钮与全文操作分开；可选独立模型，候选结果确认后应用 |
| AI 摘要、视频脉络、金句、方法、切片建议 | 默认 LLM 连接与模型 | 可与翻译共用，也可选择另一模型 |
| 保存个人理解和疑问 | 扩展本地存储 | 不调用 LLM；后续整理单独规划 |

本地翻译不要求 LLM key；一个 LLM 连接即可用于主动翻译和 AI 分析；不强迫建立多份配置。不默认跨服务自动降级，避免内容发给用户未选择的服务。

### 系统钥匙串与组件

显示组件未安装、可用、版本不兼容、启动失败，以及钥匙串等待授权、已配置、锁定或授权被拒绝。空闲未运行属于正常状态，不要求手动启动，不提供配对码表单。提供安装说明、检测组件、重试及脱敏诊断入口。配置页能在组件不可用时查看已保存非敏感配置；无法完成安全保存时不能提示成功。

## 三、连接测试和保存

按钮分别为“获取模型”“测试连接”“保存配置”。

1. 本地校验必填字段、URL、协议和模型 ID，不先发送请求。
2. 测试使用当前表单草稿，必要时临时使用本次输入的新 key；失败不替换原来可用的配置，测试成功也不自动保存。
3. “获取模型”仅在适配器支持时调用模型列表。无该接口时允许手动输入，不判整个服务不可用。
4. “测试连接”由用户明确点击发起，使用内置短测试文本，不上传视频或私人笔记；按钮附近说明可能消耗少量额度。
5. LLM 分开报告网络可达、鉴权、指定模型可调用，以及文本/结构化结果能力。真正发送小型生成请求才能把指定模型调用标为成功；成功列模型不等于生成成功。
6. Supadata 若没有可证实的不计费鉴权接口，则选择一条公开测试视频做最小字幕测试，并在执行前展示测试对象及可能消耗；不承诺零费用健康检查。
7. 保存非敏感字段和凭据引用，持久写入成功才提示“已保存”；尚未测试的配置可保存为“未验证”，但不能显示已连接。
8. 表单关闭、放弃测试或保存完成后清空新 key 的输入内存，不保存密钥草稿；普通非敏感字段可保留草稿。
9. 切换服务或模型后只对新任务生效。正在执行的任务冻结旧配置版本，不中途混用；已有结果保留，用户主动选择才重新生成。
10. 删除连接或移除密钥时先说明影响并确认；连接仍被路由或运行任务使用时禁止无声移除。账户密钥撤销必须即时生效，不为旧任务继续使用已撤销凭据。

错误以“地址不可达、密钥无效、模型不可用、额度不足、请求限流、超时、结果格式不支持”区分。不在页面展示未经脱敏的响应体、Authorization 头或服务端堆栈。

## 四、凭据保存：页面填写，服务安全使用

用户已确认使用 Mac 系统钥匙串。正常使用在设置页填写一次 API key 并由系统授权保存，换视频或重启 Chrome 无需再次填写；不增加插件自己的解锁密码。系统锁定、权限变化或升级仍可能要求授权，具体弹窗频率须实测。环境变量仅作为开发/受管凭据来源，不作为日常设置步骤。

- 当前电脑为 macOS，网页新输入的 key 经 Native Messaging 交给按需启动的本机组件，通过系统 Keychain 保存；在实现阶段验证桥接方式、系统授权及打包。[Apple Keychain 服务文档](https://developer.apple.com/documentation/security/keychain-services)
- Keychain 桥接通过受控程序接口和标准输入或原生调用传值，不把 key 放进命令行参数，不执行携带 key 的 shell 命令。
- 仍支持环境变量注入。由环境变量管理的凭据在页面标明来源并只读；切换成界面管理时新建明确的凭据来源，不暗中覆盖环境变量。
- 普通配置仅存 `credentialRef`；读配置接口只回 `credentialConfigured` 和来源，不提供“读回完整 key”接口。
- 新 key 只经独立设置页 → 受限后台管理消息 → 经来源验证的本机组件，不经过 YouTube 内容脚本，不写 chrome.storage.local、IndexedDB、日志、浏览器 URL 或配置导出。
- 已保存密钥不回填；空 key 字段表示“保留原密钥”，不是清空。清除使用单独明确操作。
- 凭据库不可用、系统拒绝授权或保存失败时，保留原有效配置，返回错误；不能降级成明文 JSON 文件。凭据和配置写入采用暂存引用、成功后切换版本的方式，避免只写了一半。
- 未开发安全存储前不收集真实 key；本轮不要求用户提供凭据。

## 五、服务调用与适配器契约

`LlmProvider` 提供 `generateText`、可选 `listModels`、`probeCapabilities`；业务流水线只接收统一的文本、usage 和错误，不自行拼接供应商 URL。

首版兼容适配器使用规范 API 根地址拼接 `/chat/completions`，按模型能力发送 model、messages 和受支持的生成参数。Bearer 鉴权只在本机组件添加，响应不携带凭据。模型列表接口为可选能力；其他鉴权形式或协议需新增适配器，不能假定修改 URL 就全部兼容。

扩展内的翻译流水线传递段标识及原文，分析流水线传递受控的全文/分块和来源映射；本机组件只执行校验后的供应商请求，不管理全片长任务。优先使用经过测试的结构化输出能力；不支持时解析文本 JSON 并校验，失败明确重试或报错，不吞错生成空卡片。

### 设置协议

| 操作 | 允许的数据与限制 |
| --- | --- |
| 读取服务资料 | 只回非敏感配置、凭据状态和当前配置修订号 |
| 保存服务资料 | 来自设置页，附 expectedRevision；新 key 为仅写入字段 |
| 测试连接/拉取模型 | 对当前草稿或已保存资料执行；响应脱敏，记录测试时间和配置指纹 |
| 保存任务路由 | 校验连接已存在、启用且模型已填写，产生新修订 |
| 停用/删除/清凭据 | 显式操作；检查路由和运行任务，不顺带删除笔记 |

后台区分 `options.html` 的设置管理消息和视频页消息。校验扩展 ID、实际 sender URL 及具体操作；不能仅凭消息里自称是设置页就放行。设置消息不要求有效 videoId；视频操作仍严格检查视频上下文。

### 网络目的地约束

- Supadata 使用固定官方目标；自定义 LLM 地址仅能在设置页建立为连接资料。视频消息只能提交已存在的 profileId，不能携带任意 URL 或请求头。
- 远程地址默认只允许 HTTPS，拒绝 URL 中的用户名、密码、query 密钥、fragment、非 HTTP 协议和异常端口；显示将发送数据的主机。
- 默认拒绝私网、链路本地、云元数据地址及解析后变成这些地址的域名；每次解析和连接验证，拒绝或重新验证重定向，防止自定义接口变成任意内网代理。
- 本地 LLM 作为显式开启的“本地服务”连接类型，限登记的回环主机和端口，不默认开放全部内网；本机凭据组件不开放管理端口。
- key 绑定服务目标，跨主机修改不得自动把旧 key 发送到新地址；要求明确重新绑定。缓存按配置版本隔离，不能复用旧目标的连接成功标记。

## 六、配置对象

| 对象 | 关键字段 |
| --- | --- |
| ProviderProfile | id、name、kind、protocol、baseUrl、defaultModel、credentialRef、credentialSource、enabled、timeoutMs、concurrency、revision |
| TaskRouting | translateProfileId、translateModel、analyzeProfileId、analyzeModel、transcriptProfileId、revision |
| ConnectionCheck | profileId 或草稿指纹、configRevision、checkedAt、检查类别、状态、脱敏错误、耗时；不保存测试 key |
| ProviderCapabilities | 能否列模型、支持的结构化输出方式、参数限制；未知与不支持分别表示 |

设置的非敏感服务资料以本机组件为权威来源；扩展可保存只读快照供离线查看，不能以陈旧快照覆盖较新配置。视频显示偏好仍由扩展保存。所有业务任务记录使用的配置版本和模型；禁用、换模型不自动删除旧 AI 结果。

## 七、本地翻译设置

常规设置中展示翻译引擎与可用状态，Chrome 本地翻译为优先验证项，无 API key 表单；只在验证支持后显示可用。首次激活、下载进度和下载失败分别处理，不借 Google 名称承诺云端免费接口。LLM 模型设置仅用于用户主动请求的翻译与分析。

## 本轮取代旧设置行为的规则（2026-09-11）

1. 每个可编辑输入框加入 SVG 清空按钮。密钥清空只影响未保存输入；旧钥匙串条目仍保留。
2. 通过服务商下拉或名称匹配选择 DeepSeek、智谱、OpenAI，更新对应 Base URL、建议模型与官方说明。改到其他服务商时清除旧模型列表与临时密钥，后台继续强制要求新地址的密钥；未知名称不猜测接口。旧版“任何连接都推荐 DeepSeek”已移除。
3. Supadata 已有字幕获取为每次 1 credit，生成参考费率为每分钟 2 credits；直接读取 YouTube 字幕不消耗 Supadata 额度。查询生成进度免费，已有字幕不可用返回 206 仍可能计 1 credit。官方依据：https://supadata.ai/pricing 与 https://github.com/supadata-ai/supadata-docs/blob/main/get-transcript.mdx 。核对日期 2026-09-11。
4. generationCreditsPerMinute 为 null 时，生成预估采用官方参考值 2；自定义值保留在折叠高级设置。此值只用于 generate 模式，不代表 native 获取费率。每个生成任务仍须确认，预估以整分钟向上取整，不等同最终账单。
5. 本机已安装 Codex CLI 0.153.4，codex login status 返回通过 ChatGPT 登录。官方支持 codex exec 复用 CLI 登录：https://developers.openai.com/codex/noninteractive 。拟通过现有 Native Messaging 组件调用本机 Codex，不导出登录令牌、不要求 API Key 或 Base URL，使用 Codex 账户额度及限制。当前仅完成可行性核实，适配器、任务权限隔离、超时取消、结构化结果与登录状态界面尚未实现；不视为已连接。

## 本机 Codex 与保存联动实现（2026-09-11）

此前“Codex 尚未实现”的状态由本节替代。连接本机 Codex 创建独立 llm 连接，connection=codex，不显示 API 地址与 Key，模型可留空使用 CLI 默认。检测登录与模型响应分别执行；可在模型分工中选择该连接用于翻译或分析。

API 旧配置无 connection 字段时保持原行为。本机连接不写钥匙串 Key，由官方 CLI 管理登录；不得自动将本机登录令牌当 API Key 使用。关闭用户配置与扩展工具，使用只读沙箱、独立工作目录和标准输入，以两分钟为单次调用上限。

保存状态独立于测试状态：未改变的已保存连接测试成功后仍为已保存；参数或临时 Key 修改则为未保存；保存全部成功更新各连接快照，保存失败不更新。只检测或测试不自动保存。

## Codex 模型必须明确（2026-09-11）

本节覆盖此前“模型可留空使用 CLI 默认”的设计。Codex 模型必须明确填写并以普通文本显示；当前试用配置保留用户所选 gpt-5.5。模型分工显示“连接名称 · 模型名称”。清空输入可编辑，但空模型不能保存或发起模型调用。一个本机 Codex 连接已存在时，入口用于定位编辑；后台禁止再次保存重复连接。


## 0.1.9 已实现：快捷键

独立分类显示“打开学习笔记”“快速记笔记”的实际绑定，从 `chrome.commands.getAll()` 读取；空值显示未设置，读取失败显示错误及刷新入口。组件独立于服务连接状态，不需要 API key 或本机组件在线。

“修改快捷键”打开 `chrome://extensions/shortcuts`。用户在那里修改，由 Chrome 自动保存，无需点击服务配置的“保存全部设置”。设置页重新获得焦点或变为可见时更新显示；组件卸载移除监听器，迟到响应不覆盖新结果。打开入口失败时提供手动地址。

Chrome 当前公开接口只提供读取和命令事件，没有扩展主动改写快捷键的接口，因此不在插件表单里假装保存原生绑定。依据：[Chrome Commands 官方说明](https://developer.chrome.com/docs/extensions/reference/api/commands)。
